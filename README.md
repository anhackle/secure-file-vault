# secure-file-vault

## Upload file

As a user

I want to upload a file

So that the system encrypts and stores it securely.

## Download with signed URL

As a user

I want to get a signed expirable link

So that I can share a file securely without exposing raw storage.

## Audit log

As an admin

I want to see logs of uploads and downloads

So that I can track who accessed which file and when.

## Token expiration

As a user

I want the signed link to automatically expire

So that the file cannot be accessed indefinitely.

## Access control

As a user

I want only authorized accounts to upload and download

So that unauthorized people cannot misuse the service.
